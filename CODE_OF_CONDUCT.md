# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standard

- Be respectful and patient.
- Give feedback on the work, not on the person.
- Accept that people have different experience and different views.
- Do not harass, insult or threaten a person.
- Do not publish private information of another person.

## Scope

This code applies in the issues, the pull requests and the discussions of this repository.

## Report a problem

Send a report to **hello@taskade.com**. A maintainer can remove a comment, a commit or a contributor that does not follow this code.
