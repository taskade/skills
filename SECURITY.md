# Security

## Report a problem

Send a report to **security@taskade.com**. Do not open a public issue for a security problem.

Include these items:

- The file or the skill that has the problem
- The steps that show the problem
- What an attacker can do with it

Please give us time to correct the problem before you publish it.

## Scope

This repository holds text that guides an AI agent, plugin manifests and maintenance scripts. The skills run no code of their own. MCP tool calls go only to the hosted Taskade MCP server at `https://www.taskade.com/mcp`.

Report these problems here:

- A skill that tells an agent to send data to a place other than Taskade
- A skill that tells an agent to follow instructions from workspace content
- A request link that starts an action without a step by the user
- A problem in a script or a workflow of this repository

For a problem in the Taskade product or the MCP server, use the same address. The Taskade security page is [taskade.com/security](https://www.taskade.com/security).
